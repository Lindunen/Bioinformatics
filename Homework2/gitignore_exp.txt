.gitignore - это специальный файл в Git-репозитории, который указывает, 
какие файлы и папки Git должен игнорировать (не отслеживать и не добавлять в репозиторий)
Временные файлы: .tmp, .log, .cache,
конфиденциальные данные,
кэш python**: __pycache__/, .pyc
большие файлы: датасеты, модели (как наш ClinicalTrial2026/)


Мы добавили ClinicalTrial2026/ в .gitignore, потому что:
- Это сгенерированная структура проекта, которую можно воссоздать скриптом
- Папка может содержать большие данные, которые не нужно хранить в Git
- Каждый раз при запуске скрипта создается новая папка (это засоряло бы репозиторий)
